# 036 - Minimax Game Solver

Vanilla JavaScript minimax game solver with tic-tac-toe state evaluation, alpha-beta pruning, optimal move search, node telemetry, Canvas 2D board rendering, benchmark mode, PNG export, and JSON evidence.

## What It Does

- Evaluates deterministic tic-tac-toe board states.
- Searches optimal moves with minimax and alpha-beta pruning.
- Reports chosen move, score, legal moves, explored nodes, and prune count.

## Validation

npm run test:036
