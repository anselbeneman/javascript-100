# 022 - MCTS Strategy Lab

Vanilla JavaScript Monte Carlo Tree Search laboratory for deterministic game AI.

## What it demonstrates

- UCB1 node selection, expansion, rollout simulation, and backpropagation.
- Deterministic seeded search over tic-tac-toe game states.
- Canvas 2D rendering for the board and a compact search tree.
- Search metrics for nodes, depth, visits, branching, best move, and win rate.
- Benchmark timing, JSON export, PNG capture, and technical report copy.
