# 028 - L-System Garden

Vanilla JavaScript L-system generator with deterministic rewriting, turtle graphics, bracketed branching, Canvas 2D rendering, structural metrics, benchmark mode, PNG export, and JSON evidence.

## What It Does

- Expands formal grammar rules into deterministic plant and crystal structures.
- Converts grammar tokens into turtle graphics with branch stacks and depth metrics.
- Exposes a small testable `LSystemCore` API for rewriting, geometry, analysis, and benchmarking.
