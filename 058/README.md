# 058 - Segment Tree Range Min

Vanilla JavaScript segment tree range-min lab with deterministic arrays, recursive tree construction, range queries, brute-force validation, Canvas 2D query rendering, benchmark mode, and JSON export.

## What It Does

- Builds a recursive segment tree.
- Runs sampled range-minimum queries.
- Compares each query with brute force.

node scripts/test-project-058.js
npm run test:projects
