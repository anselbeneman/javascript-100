# 023 - Probabilistic Data Lab

Vanilla JavaScript probabilistic data structure studio.

## What it demonstrates

- Bloom filter insertion and membership checks.
- HyperLogLog cardinality estimation.
- Deterministic stream generation with duplicates.
- False-positive analysis, fill ratio, HLL error, and memory metrics.
- Canvas 2D rendering for bitsets and registers.
