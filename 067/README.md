# 067 - Knapsack DP Optimizer

A standalone vanilla JavaScript 0/1 knapsack workbench that solves deterministic weighted item sets with dynamic programming.

## What it demonstrates

- Capacity-indexed dynamic-programming rows.
- Backtracking from the optimal table state.
- Greedy ratio baseline comparison.
- Capacity, value, and chosen-item validation.
- Canvas 2D visualization plus PNG/JSON exports.
