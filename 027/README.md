# 027 - Pratt Parser Studio

Vanilla JavaScript expression parser studio built around Pratt parsing.

## What it demonstrates

- Tokenization and recursive expression parsing with binding powers.
- Prefix negation, infix operators, precedence, and right-associative exponentiation.
- AST evaluation and structural metrics.
- Canvas 2D syntax tree rendering, benchmark timing, JSON export, PNG capture, and report copy.
