# 055 - Stable Matching Solver

Vanilla JavaScript stable matching solver with deterministic preference tables, Gale-Shapley proposals, blocking-pair validation, Canvas 2D matching rendering, benchmark mode, PNG export, and JSON evidence.

## What It Does

- Builds deterministic preference tables.
- Solves stable matching with Gale-Shapley proposals.
- Validates absence of blocking pairs.

## Validation

From the repository root:

```bash
node scripts/test-project-055.js
npm run test:projects
npm run smoke:projects
```
