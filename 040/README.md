# 040 - AVL Tree Balancer

Vanilla JavaScript AVL tree balancer with deterministic key insertion, left and right rotations, height tracking, balance-factor validation, Canvas 2D tree rendering, benchmark mode, PNG export, and JSON evidence.

## What It Does

- Inserts deterministic keys while preserving AVL balance.
- Executes single and double rotations as needed.
- Reports tree height, rotation count, maximum balance factor, and ordered traversal validity.
