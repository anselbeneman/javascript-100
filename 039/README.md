# 039 - B-Tree Index Visualizer

Vanilla JavaScript B-tree index visualizer with deterministic key insertion, node splitting, logarithmic search, height and occupancy metrics, Canvas 2D tree rendering, benchmark mode, PNG export, and JSON evidence.

## What It Does

- Inserts deterministic keys into a B-tree with node splitting.
- Searches selected keys and reports search depth.
- Tracks height, node count, average occupancy, and sorted key integrity.
