# 048 - Dijkstra Routing Grid

Vanilla JavaScript Dijkstra routing grid with deterministic weighted graphs, shortest-path reconstruction, visited-node telemetry, Canvas 2D route rendering, benchmark mode, PNG export, and JSON evidence.

## What It Does

- Builds deterministic weighted graph links.
- Solves shortest paths with Dijkstra relaxation.
- Renders the route and verifies endpoint reconstruction.
