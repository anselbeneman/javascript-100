# 068 - RANSAC Line Fitter

A standalone vanilla JavaScript robust line-fitting demo that separates noisy inliers from deliberate outliers.

## What it demonstrates

- Seeded synthetic data with controllable outliers.
- RANSAC two-point model sampling.
- Distance-threshold inlier scoring.
- Least-squares refinement on the winning inlier set.
- Canvas 2D visualization plus PNG/JSON exports.
