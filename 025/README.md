# 025 - Regex NFA Engine

Vanilla JavaScript regular-expression engine built with an explicit NFA simulation.

## What it demonstrates

- Regex tokenization, concatenation insertion, and postfix conversion.
- Thompson-style NFA construction for literals, alternation, concatenation, and Kleene star.
- Epsilon-closure simulation and match tracing.
- Canvas 2D graph rendering, metrics, benchmark timing, JSON export, PNG capture, and report copy.
