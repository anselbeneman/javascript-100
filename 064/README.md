# 064 - Online Perceptron Trainer

Vanilla JavaScript online perceptron trainer with deterministic separable data, mistake-driven updates, accuracy verification, Canvas 2D classifier rendering, benchmark mode, PNG export, and JSON evidence.

## What It Does

- Trains an online perceptron on separable samples.
- Tracks mistake-driven weight updates.
- Verifies final classifier accuracy.

## Validation

From the repository root:

```bash
node scripts/test-project-064.js
npm run test:projects
npm run smoke:projects
```
