# 054 - CRC32 Checksum Lab

Vanilla JavaScript CRC32 checksum lab with lookup-table generation, incremental chunk hashing, full-message verification, Canvas 2D checksum rendering, benchmark mode, PNG export, and JSON evidence.

## What It Does

- Generates the CRC32 lookup table in JavaScript.
- Compares full-message and incremental chunk checksums.
- Renders chunk checksum evolution as evidence.

## Validation

From the repository root:

```bash
node scripts/test-project-054.js
npm run test:projects
npm run smoke:projects
```
