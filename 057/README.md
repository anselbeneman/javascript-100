# 057 - Min-Heap Priority Queue

Vanilla JavaScript min-heap priority queue with deterministic insertions, bubble-up and sink-down operations, sorted pop validation, Canvas 2D order rendering, benchmark mode, PNG export, and JSON evidence.

## What It Does

- Pushes deterministic priorities into a binary heap.
- Pops values in sorted order.
- Tracks swaps and verifies heap output ordering.
