# 056 - Union-Find Network Lab

Vanilla JavaScript union-find network lab with deterministic edge streams, path compression, union by rank, component counting, Canvas 2D connectivity rendering, benchmark mode, PNG export, and JSON evidence.

## What It Does

- Builds disjoint sets with path compression.
- Unions deterministic connectivity edges.
- Reports component count, union count, and validation bounds.

node scripts/test-project-056.js
