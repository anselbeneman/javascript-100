# 052 - Fenwick Range Sum Lab

Vanilla JavaScript Fenwick range-sum lab with deterministic numeric arrays, point updates, prefix queries, brute-force validation, Canvas 2D query rendering, benchmark mode, PNG export, and JSON evidence.

## What It Does

- Builds a Fenwick tree over deterministic values.
- Runs range queries via prefix sums.
- Validates sampled queries against brute force.

## Validation

From the repository root:

```bash
node scripts/test-project-052.js
npm run test:projects
npm run smoke:projects
```
