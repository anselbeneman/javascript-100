# 043 - Logistic Regression Trainer

Vanilla JavaScript logistic regression trainer with deterministic binary datasets, sigmoid scoring, gradient descent, loss and accuracy telemetry, Canvas 2D decision-boundary rendering, benchmark mode, and JSON export.

## What It Does

- Generates deterministic binary classification data.
- Trains a logistic regression model with gradient descent.
- Reports loss, accuracy, weights, epochs, and benchmark timing.

## Validation

From the repository root:

```bash
node scripts/test-project-043.js
npm run test:projects
npm run smoke:projects
```
