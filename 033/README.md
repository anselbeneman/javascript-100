# 033 - Huffman Compression Lab

Vanilla JavaScript Huffman compression lab with frequency analysis, deterministic priority queue tree building, prefix-code encoding and decoding, Canvas 2D code visualization, benchmark mode, and JSON export.

## What It Does

- Counts character frequencies and builds a deterministic Huffman tree.
- Produces prefix codes, encodes text, and verifies decoded output.
- Reports encoded bits, fixed-width bits, compression ratio, unique symbols, and tree depth.
