# 061 - Quickselect Median Lab

Vanilla JavaScript quickselect median lab with deterministic arrays, in-place partitioning, kth-order selection, sorted-array verification, Canvas 2D rank rendering, benchmark mode, and JSON export.

## What It Does

- Selects the median without fully sorting.
- Verifies the selected value against sorted order.
- Renders rank distribution evidence.

## Validation

From the repository root:

```bash
node scripts/test-project-061.js
npm run test:projects
npm run smoke:projects
```
