# 034 - Decision Tree Lab

Vanilla JavaScript decision tree lab with deterministic synthetic data, Gini impurity scoring, recursive feature splits, classifier evaluation, Canvas 2D tree rendering, benchmark mode, and JSON export.

## What It Does

- Creates deterministic classifier data with latency, interaction, and visual-score features.
- Builds a recursive decision tree using Gini gain and guarded split thresholds.
- Reports train/test accuracy, node count, impurity, and held-out evaluation.

## Validation

From the repository root:

```bash
npm run test:034
npm run smoke:projects
```
