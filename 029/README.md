# 029 - A-Star Pathfinding Lab

Vanilla JavaScript A-star pathfinding lab with deterministic obstacle fields, binary-heap frontier, Manhattan and diagonal heuristics, Canvas 2D route rendering, telemetry, benchmark mode, and JSON export.

## What It Does

- Builds reproducible obstacle grids with protected solvable corridors.
- Solves routes with a binary heap frontier and selectable heuristics.
- Reports path length, visited cells, frontier pushes, turns, and route cost.
