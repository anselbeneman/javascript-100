# 026 - BM25 Search Lab

Vanilla JavaScript search-ranking studio built around BM25.

## What it demonstrates

- Tokenization and inverted index construction.
- BM25 scoring with IDF, document length normalization, and top-k ranking.
- Query explanation through per-term score contributions.
- Canvas 2D score visualization, benchmark timing, JSON export, PNG capture, and report copy.

## Validation

npm run test:026
npm run smoke:projects
