# 060 - KMP String Search Lab

Vanilla JavaScript KMP string search lab with prefix-function construction, linear scanning, brute-force match verification, Canvas 2D prefix rendering, benchmark mode, PNG export, and JSON evidence.

## What It Does

- Builds the KMP prefix table.
- Finds every pattern occurrence in linear time.
- Verifies matches against native regular expression scans.

## Validation

From the repository root:

```bash
node scripts/test-project-060.js
npm run test:projects
npm run smoke:projects
```
