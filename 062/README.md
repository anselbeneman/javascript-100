# 062 - Reservoir Sampling Lab

Vanilla JavaScript reservoir sampling lab with deterministic streams, fixed-size sample replacement, uniqueness checks, Canvas 2D sample rendering, benchmark mode, PNG export, and JSON evidence.

## What It Does

- Samples a fixed-size reservoir from a stream.
- Uses deterministic pseudo-random replacement.
- Verifies sample size, uniqueness, and bounds.

## Validation

From the repository root:

```bash
node scripts/test-project-062.js
npm run test:projects
npm run smoke:projects
```
