# 046 - Markov Text Chain Lab

Vanilla JavaScript Markov text chain lab with tokenization, transition tables, deterministic corpus analysis, entropy metrics, Canvas 2D distribution rendering, benchmark mode, PNG export, and JSON evidence.

## What It Does

- Builds token transition tables from a deterministic technical corpus.
- Computes average transition entropy and sequence metrics.
- Renders transition distribution evidence on Canvas 2D.
